# Jev-Chat 使用与配置说明

> 一份看懂怎么装、怎么填、怎么用的操作手册。功能亮点见仓库根目录 [README](../README.md)。

---

## 一、快速上手（三步）

1. **装插件**：deb 装完**重启微信**，打开入口 **微信 → 我 → 设置 → Jev Chat**。
2. **填 API**：「建议回复」页填服务地址 / Key / 模型（生成层，必填）；「意图判断」页选个预设只填 Key（判断层，可不填）。
3. **启用并选人**：主页「启用插件」→ 打开开关 → 选择联系人。之后对方发消息，消息下方自动出现分析卡片和 4 条建议回复，点 ➤ 直接发送。

> 判断层不配 Key 也能用：走本地规则兜底（含收线判别），判断层零 token 消耗。建议回复、读心、祖师爷点评/复盘、记忆更新都走生成层，**生成层 Key 必填**。

## 二、聊天界面：你会看到什么

### 1. 分析卡片（判断层产出）

对方每条文本消息下方自动出现：

| 卡片行 | 含义 |
| --- | --- |
| **称呼 [复盘]** | 标题显示微信备注（无备注用昵称）；右侧「复盘」小按钮见下 |
| **会话状态** | 只在特殊态势出现：升温 / 冲突 / 紧急 / 台阶期 / 破冰期，提示当前该收着还是顺着 |
| **分析** | 一句话读心：对方此刻的状态、这句话的潜台词、怎么接 |
| **祖师爷** | 人设视角局评（意图判断页开启，默认关） |
| **本轮策略** | 承接 / 推进 / 收线……这一轮的方向 |
| **当前真实意图** | 概率最高的意图 + 置信度，如「想确认你在不在乎：52%」 |
| **关系 / 危险等级 / 情绪能量** | 关系定位、回错话的代价（0-10）、对方情绪温度 |
| **是否应该立刻回复 / 最佳动作** | 立刻回还是缓一缓；这轮最该做的事 |

### 2. 建议回复（生成层产出）

- **4 条候选**：按所选话术（每种 2 条）或真实角度 4 档出，点 ➤ 以你的口吻直接发出；
- **🔄 换一批**：先吐备用库存，库存用完自动重新生成；
- **快捷回复**：键盘上方常驻建议，不展开卡片也能直接选（建议回复页开启）。

### 3. 复盘按钮（手动触发）

卡片右上角「复盘」，卡住了才点、不自动跑：把该会话**最近 20 条对话（含你的发言）+ 祖师爷全量框架**（5 心智模型 + 9 启发式，逐条忠实原 skill）发给生成层，返回 400 字左右复盘——**整体局评 / 你的问题（具体到哪句发坏了）/ 对方心态轨迹 / 下一步怎么打**。走生成层 token（一次约 1 分钱）。会话记录不跨重启：重启微信后只能复盘本次启动以来的对话。

## 三、设置主页导览

主页九个入口，点进去才是各自的具体设置：

| 入口 | 管什么 |
| --- | --- |
| **基础功能** | 防撤回、微信运动步数、后台保活（全局功能，不受名单影响） |
| **启用插件** | 分析类功能总闸 + 联系人白名单 |
| **意图判断** | 判断层开关与配置（卡片、会话状态、点评、上下文、服务商） |
| **建议回复** | 生成层开关与配置（服务商、思考模式、话术、人设） |
| **记忆档案** | 相处笔记与自动回复（按联系人） |
| **用量统计** | 判断层 / 生成层今日+累计 token，可清零 |
| **关于插件** | 插件介绍：核心能力、隐私说明、当前版本 |
| **打赏作者** | 打赏二维码（原图内嵌在插件里，无需联网），长按可保存到相册 |
| **插件版本** | 构建号与 deb 文件名对得上 = 装对了 |

## 四、各设置页详解

### 1. 基础功能

| 设置项 | 说明 |
| --- | --- |
| **后台运行** | 后台保活（场景修复 + 静音音频），无悬浮窗、零视觉打扰 |
| **消息防撤** | 对方撤回消息时提示「已拦截 XX 撤回的消息」，名字标好 |
| **微信运动** | 步数按「总步数」目标全天平滑递增；「瞬间 88888」一键到位 |

### 2. 启用插件（总闸 + 名单）

| 设置项 | 说明 |
| --- | --- |
| **启用插件（开关）** | 开 = 只有名单里的联系人启用意图分析、建议回复、快捷回复、自动回复、记忆档案、会话状态（名单外**完全不跑**，零 token）；关 = 以上功能对所有人停用。防撤回 / 微信运动 / 后台保活不受影响 |
| **选择联系人** | **微信原生选择界面**（带头像、带搜索、只列真人好友），进去自动勾上现有名单，点右上角「完成」保存即时生效；移出名单会清掉该会话的分析缓存和会话状态（相处笔记保留，不再更新） |

### 3. 意图判断（判断层）

配置项始终显示；「显示分析卡片」只控制卡片显隐。

| 设置项 | 说明 |
| --- | --- |
| **显示分析卡片** | 关了卡片不出，但**判断仍在后台跑**（生成层约束、自动回复的收线保护要用）；判断层和生成层都关才完全不处理；没配判断层 Key 走本地规则兜底 |
| **会话状态** | 跨消息会话状态机（默认开）：连续信号累积成「紧张度 + 阶段」——**升温 → 冲突 → 紧急**（连续 3 条负面升级）、对方给台阶进**台阶期**刹车、吵完进**缓和期**、跨天没和好再开口是**破冰期**。生成层按阶段自动改口吻（吵架=短句放软认错不抬杠，台阶期=顺着翻篇，破冰期=点破僵局别翻旧账）；**冲突 / 紧急 / 台阶期 / 破冰期自动回复暂停**，判断层也带[前情]分析。关掉回到逐条独立分析 |
| **祖师爷点评** | 卡片多一行「祖师爷」局评（默认关）：点破对方这句话说明什么 + 一个具体动作建议。上下文**按判断层的方式给**；**独立小请求走生成层配置（需生成层 Key）**，与判断层完全隔离——不进意图/风险/策略判断，也不影响建议回复风格（想按人设回话用「话术选择」里的深情祖师爷）。超 120 字截断，失败静默 |
| **关联上下文** | 最近 N 条消息一起给模型参考，建议 **5～10 条**；「不关联」只看当前这条 |
| **服务预设 / 服务地址 / Key / 模型** | 见下表 |

**服务预设怎么选**：

| 预设 | 自动填入的地址 | 自动填入的模型 | 你还需要做 |
| --- | --- | --- | --- |
| **博查** | `https://jev.bocha.cn/v1/systemone` | `bocha-jev-v1` | 只填 Key |
| **阿里百炼** | `https://llm-tg7bn69qnisd67ok.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/systemone` | `decision-model-preview` | 只填 Key |
| **自定义** | 保留当前值，可手动修改 | 同左 | 地址、模型、Key 全部手填 |

- 预设选中后地址/模型**锁定**防误改（Key 照常可填可改）；切回「自定义」解锁编辑。
- 两个预设都是 SystemOne 专用判断接口，插件自动走对应协议。
- 自定义地址规则：地址含 `systemone` 走专用判断接口；否则按通用 `chat/completions` 处理（地址填到 `/v1` 为止）。

### 4. 建议回复（生成层）

打开「建议消息」开关后才显示以下各项。

**基础三项**：

| 设置项 | 怎么填 |
| --- | --- |
| **服务地址** | OpenAI 兼容地址，**填到 `/v1` 为止**（`/chat/completions` 插件自动拼），见下表 |
| **Key密钥** | 对应平台的 API Key |
| **模型** | 平台的模型 ID，如 `qwen3.8-max`、`glm-4.6`、`deepseek-v3` |

| 平台 | 服务地址 |
| --- | --- |
| 阿里百炼（专属接入点） | `https://llm-tg7bn69qnisd67ok.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |
| 阿里百炼（公共） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| SiliconFlow 硅基流动 | `https://api.siliconflow.cn/v1` |
| OpenAI | `https://api.openai.com/v1` |

**思考模式关闭**（重点：填错会变慢、多花钱）——用带「深度思考」的模型时按服务商选：

| 你用的模型/平台 | 该选的选项 | 实际发送的参数 |
| --- | --- | --- |
| 不确定 / 混用 | **自动识别**（默认） | 按服务地址自动挑下面两种之一 |
| 模型本身不思考（deepseek-v3、glm-4-flash 等） | **不发送** | 不带任何参数 |
| 阿里百炼 Qwen3、SiliconFlow Qwen3 | **百炼 enable_thinking** | `"enable_thinking": false` |
| 智谱 GLM-4.5/4.6、豆包思考模型 | **GLM/豆包 thinking** | `"thinking": {"type": "disabled"}` |
| OpenAI GPT-5 / o 系列 | **OpenAI effort** | `"reasoning_effort": "minimal"` |
| OpenRouter 网关 | **OpenRouter** | `"reasoning": {"enabled": false}` |
| Gemini（经兼容网关） | **Gemini budget** | `"thinking_budget": 0` |
| vLLM 自部署 Qwen3 | **vLLM 自部署** | `"chat_template_kwargs": {"enable_thinking": false}` |

> 只影响生成层（读心、起草、换一批、记忆更新、点评、复盘）。判断层预设接口自动处理。

**回复行为**：

| 设置项 | 说明 |
| --- | --- |
| **快捷回复** | 键盘上方常驻建议回复，不展开分析卡片也能直接选 |
| **话术模式（真实口吻）** | 开 = 模仿「我的说话习惯」落笔，话术只定方向；关 = 纯按所选话术人设回 |
| **话术选择** | 17 种内置人设可多选：高情商话术、贴吧老哥、拒绝加班、卑微乙方、稳如老狗、已读乱回、鱼塘主、职场黑话、阴阳怪气、情绪价值、夸夸、讨好型人格、狗头军师系列、**深情祖师爷**系列（自信不讨好；「·抽离」专治冷淡敷衍） |
| **自定义人设** | 自己写人设卡（名称 + 指令正文），保存后并入「话术选择」可选列表，可与内置混选；左滑删除、点进去编辑，改动即时生效 |
| **关联上下文** | 生成层自己的上下文条数（与判断层分开设），建议 5～10 条 |

### 5. 记忆档案

| 设置项 | 说明 |
| --- | --- |
| **记忆档案（开关）** | 总开关，关 = 暂停读写（已存内容保留） |
| **查看记忆档案** | 看每个人的相处笔记和自动回复设置 |
| **清除记忆档案** | **全部**删除（单个删除在档案列表左滑） |
| **档案文件** | 显示各层存储状态（主文件 / 两代备份 / 系统镜像 / 沙盒外备份，含是否可读、几人）；档案丢失时对照这里定位问题 |

**日常操作**：

- **自动回复（按联系人）**：档案**列表页每一行右侧**——「自动回复」开关 + 「第N条 ▸」并排。开关打开的联系人收到消息才自动回复，点「第N条」选自动发第几条（1～4）；不开的人永远只出建议、不自动发。
- **自动成长**：每聊约 2 分钟，模型自动总结更新九大板块（这是TA / 我们之间 / 长期话题 / 近期动态 / 动态小结 / TA最近 / 待办承诺 / 画像小结 / 我的习惯）。「我的习惯」**只从有正反馈的发言提炼**——你发出去、对方下一句接住了（继续话题/反问/发表情/约下一次）才算数，被冷落的说法不学。
- **称呼与性别自动同步**：标题优先微信**备注**，没备注显示**昵称**；性别跟随微信资料，对方设为未知就不显示、也不传给模型。
- **手动编辑**：档案详情页右上「编辑」→ 改文字 →「完成」保存。没写到的板块保留原值，不会误清空。
- **未和解档案（跨天吵架）**：冲突没有台阶地沉默后，档案挂一条「未和解」记录；隔天对方再开口进入**破冰期**（生成层按破冰语境接话、自动回复暂停）。和好后一般自动清除；判不准时在**档案详情页左上「已和好」**手动清档。
- **删除一个人**：档案**列表左滑**该联系人 → 删除（弹确认）。删除后再发消息会重新建档（称呼/性别重新识别，旧笔记不恢复，自动回复开关重置为关）。

## 五、常见问题

**Q：分析卡片标题显示的是什么名字？**
微信备注优先，其次昵称；都没有就显示「- 意图 -」。

**Q：收到消息到出卡片很慢？**
基本是思考模式没关对。去「建议回复 → 思考模式关闭」按上表选对；判断层慢就检查预设 / Key 是否填对。

**Q：建议回复不满意？**
点 🔄 换一批（先出备用库存，用完自动重新生成）；或调整话术选择 / 关联上下文条数。

**Q：开了祖师爷点评为什么不显示？**
点评走**生成层**配置：确认「建议回复」页 Key 已填；点评失败会静默不占位；对方消息没触发分析卡片时也没有点评。

**Q：装包 / 重启微信后，复盘只剩最近几条对话？**
正常。会话记录只在内存里（最近 20 条、不跨重启），重启后从零积累；相处笔记不受影响（落盘保留）。想复盘完整对话，重启后先聊几轮再点。

**Q：开了自动回复为什么没有自动发？**
按顺序检查：①「建议消息」总开关开着没；②这个联系人的开关在记忆档案列表里打开没；③对方发的是不是收尾消息（晚安/睡了/去忙）或纯应付（哈哈/嗯）——这两种故意不回，像真人；④分析期间你手动回复过或来了新消息——旧结果作废不回；⑤卡片有没有「会话状态」行——**冲突/紧急/台阶期/破冰期自动回复暂停**，状态缓和后自动恢复。

**Q：Key 会泄露吗？**
Key 只存在你手机本机，请求直连你填的服务地址，插件不经过任何第三方服务器。

**Q：单删和全清的区别？**
单删只删那一个人（列表左滑）；「清除记忆档案」是所有人一起删。两者都不可恢复。

**Q：怎么确认装的是刚编译的新包？**
版本号带构建时间戳（如 `1.1.1-20261022.1259`）：设置页标题、主页「插件版本」行显示的就是当前运行的时间戳，和 deb 文件名对得上就是装对了；对不上就是包装错了 / 没重启微信。
