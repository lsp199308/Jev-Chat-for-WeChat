# 📖 Jev-Chat 使用说明

> 面向使用者的完整手册：从装好到用熟。技术原理见 [README.md](README.md)。

---

## 🚀 五分钟上手

```text
① 安装并重启微信
② 微信 → 我 → 设置 → Jev Chat（或「插件」页里的 Jev Chat）
③ 「意图判断」和「建议回复」页各填一层：接口地址 / Key / 模型
④ 「启用插件」→ 打开总开关 → 选联系人（群在「选择群聊」里选）
⑤ 回聊天页发条消息 → 卡片弹出 → 点 ➤ 发送第一条建议回复
```

> 💡 两层 API 可以填同一家；只有生成层也能用（判断走本地规则兜底，零 token）。

## 💬 日常使用

### 分析卡片

每条白名单内的新消息下方自动出现卡片，从上到下：**一句话读心 → 本轮策略 → 真实意图 → 关系 → 危险等级 → 情绪能量 → 是否立刻回 → 最佳动作**，底部挂 4 条建议回复。

- **➤ 发送**：点候选右侧纸飞机，直接以你的身份发出
- **🔄 换一批**：先用备用库存，用完自动重新生成（排除看过的）
- **长按纸飞机** = 「这条不像我」：进起草红线与画像纠错层，下次不再这么写
- **右上「复盘」**：卡住了点一下，祖师爷 400 字复盘整段对话（局评 / 你哪句发坏了 / 下一步怎么打）
- 卡片字段太多？「卡片显示字段」里逐类关掉不看的

### 会话状态（自动）

连续冷暴力 → **紧急**；对方递台阶 → **刹车**；跨天没和好 → **破冰期**。冲突 / 台阶 / 破冰期自动回复暂停，人工拿捏。跨天未和解时记忆详情页脚会出现「跨天未和解，点此标记已和好」，和好了点一下清档。

### 自动回复

记忆档案列表行右侧开关 = 对该联系人自动回；「第N条 ▸」选自动发第几条候选。群的在群笔记列表行右侧。防线：收线 / 纯应付不回、10 秒内最多 2 条、AI 代发不进画像。

## 🗂 记忆档案

### 相处笔记（12 节，自动成长）

这是TA / 我们之间 / 长期话题 / 近期动态 / 动态小结 / TA最近 / 待办承诺 / 画像小结 / 我的习惯 / TA的表达习惯 / TA的吵架模式 / TA的和好方式。

点右上「编辑」可直接改正文——出现的节整节生效，没出现的保留；改完自动落盘。

### 【备注】写死的事实（模型只读）

正文最底部的【备注】节，写**必须遵守**的事实：

```text
【备注】
对花生芒果过敏，永远别提相关甜品
我是做后端的，别建议我转行
每周三晚固定加班，别约这个时间
```

模型每轮更新笔记**动不了这一节**（结构保证，不是口头约定），判断 / 读心 / 起草都会遵守；随手改随手生效。清空该节内容即删除。

### 联系人规则（右上「规则」按钮）

对特定的人换打法：**判断规则**（意图怎么判）+ **起草规则**（怎么说话），非空即生效、清空即回默认。页面顶部「套用模板」内置 4 套起笔：**家人（父母长辈）/ 领导·重要客户 / 朋友 / 伴侣·暧昧对象**——点选填入后直接改，字体样式不动。

> 同一页还有「注入我的口吻」开关（默认关）：开了候选落笔带你的个人腔调，与规则冲突时以规则为准。

## 👥 群聊

### 群聊笔记（记忆档案 → 群聊笔记）

每个白名单群一份档案：**群类型 / 触发方式 / 自动回复 / 笔记正文**。

**群类型**五选一：闲聊通用 · 商业客服 · 家族群 · 公司群 · 游戏群——决定意图集、接话口径、笔记结构。**新群首次触发会按群名自动猜一次类型**（「XX公司客服群」→ 客服），猜错在这里改。没专属类型的群（同学群 / 家长群 / 兴趣群）保持「闲聊通用」，用群自定义规则贴合。

**触发方式三选一**：

| 档位 | 行为 | 适合 |
| --- | --- | --- |
| @我才回 | 只分析 @你的消息 | 默认推荐，防刷屏 |
| **值得回才回** | 每条先过小问卷：点名提问 / 直接问你的事 / 清晰求助才回，其余静默跳过 | 活跃客服群 / 客户群 |
| 所有消息都回 | 每条都分析 | 极低频重要群 |

> 「值得回」判定每 60 秒最多一次、判定本身约 60 token；日志搜 `[值得回]` 可看每条判定结果。

### 业务知识（答价格的关键）

群笔记详情正文最底部的【业务知识】节，写死你店铺的硬信息：

```text
【业务知识】
店铺：XX服装店
主营：女装（卫衣/T恤/牛仔裤）
价格带：卫衣 89-129，T恤 39-59，牛仔裤 99-159
发货：48小时内发，中通/圆通
售后：7天无理由，已开运费险
活动：满199减20
```

**模型只读不改**（结构保证），判断 / 起草 / 读心全部以此为准——群里问「老板衣服怎么卖」，报价就从这里来。

### 群自定义规则（每群各管各的）

群聊自定义列表 → 点群名进详情：**判断规则**（这个群消息怎么判）+ **起草规则**（怎么说话），非空即生效。顶部「套用模板」内置 5 套：**淘宝/电商客服 · 工作群（领导在）· 同事闲聊群 · 家长群 · 兴趣群**——套用后直接改。

**淘宝客服群配方**（三件套）：

```text
① 群类型 → 商业客服
② 套用「淘宝/电商客服群」模板改措辞（判断+起草两张卡）
③ 群笔记【业务知识】写价格 / 发货 / 售后
```

每群还有「注入我的口吻」开关（默认关）：客服群保持关 = 纯专业口径；朋友性质的群打开 = 落笔带你的腔调。

> ⚠️ 极速模式与群自定义 / 群类型问卷互斥：写了规则的群自动回完整链路，规则照常生效。

## ✍️ 回复风格与口吻

| 风格 | 出候选方式 |
| --- | --- |
| **话术模式** | 按勾选的人设出（17 种内置 + 自定义人设卡，1~4 个依次分配位置） |
| **真实口吻** | 稳妥 / 敢 / 贴 / 活 四档，像你随手打字 |

- **模仿我的口吻**（全局开关）：开=注入「我的说话习惯」+「我的数字画像」（六层：硬规则/身份/表达/决策/人际/纠错，每 20 小时自动修订，可手改）；关=人设就是全部
- **自定义人设**：自己写人设卡，或粘贴社区 SKILL.md 一键清洗
- **数字分身语料**：一键导出 jsonl（喂 LoRA 微调）+ markdown 对话材料（喂 distilly 蒸馏），导出的就是「你」的完整语料

## ⚡ 省流与极速

| 开关 | 效果 |
| --- | --- |
| 应付消息不分析 | 哈哈 / 嗯 / 纯表情 / 纯链接本地跳过，零请求 |
| 同内容复用 | 同会话同内容 5 分钟内直接沿用上次分析 |
| 读心并入判断 | 读心随判断问卷一起出，每条消息少一次请求 |
| **极速模式** | 判断+候选合并一次请求（2→1）；设了群类型或写了规则的群自动回完整链路 |

## 📦 授权与备份

- **授权**：设置 → 授权，导入 `.wiaauth` 文件。未授权也能用判断 + 生成基本回复；微信未登录时导入会提示「已保存，登录后自动生效」
- **导出 / 导入**：全部设置 + 记忆档案一键打包（JSON 分享 / AirDrop / 文件 App）；两阶段校验，坏文件只拒收；换机 API Key 走「完整导出」（Key 存 Keychain）

## 🔍 排查与日志

打开**开发者模式**（主页底部）→ 主页「查看日志」进插件内阅读器（分类着色、可分享）。常用标签：

| 标签 | 看什么 |
| --- | --- |
| `[消息] [群]` | 消息进来没、名单内吗、@我没 |
| `[回灌]` | 历史补了哪些、上下文是否重取 |
| `[等待] [分步]` | 分段合并窗、判断先上屏 / 读心随后 |
| `[HTTP→] [HTTP←]` | 每次请求全文与响应（排 prompt 问题靠它） |
| `[值得回]` | 三档中档的每条判定结果 |
| `[群自定义] [联系人规则]` | 规则切换与模板套用 |
| `[监控]` | 崩溃 / 卡顿 / 上次异常退出 |

**常见问题**：

<details>
<summary><b>插件入口在哪？</b></summary>

微信 → 我 → 设置 → Jev Chat；或微信「插件」页里的 Jev Chat（入口位置可在设置里切换）。
</details>

<details>
<summary><b>收消息没有卡片？</b></summary>

按序检查：① 启用插件总开关 + 该联系人/群在名单里；② 判断层或生成层至少配好一层；③ 群消息需要 @我（或触发档位不是「@我才回」）；④「值得回」档有 60 秒冷却，连续消息只有第一条参与判定。
</details>

<details>
<summary><b>候选只有 2 条、后面是固定文案？</b></summary>

旧版自定义规则的配对错位，升级到本版即修复（契约改要 8 条）。
</details>

<details>
<summary><b>开了极速模式，群规则好像没生效？</b></summary>

极速与自定义互斥是设计行为：写了规则的群自动回完整链路，规则照常生效；其它群照常极速。
</details>

<details>
<summary><b>改了业务知识 / 备注没生效？</b></summary>

编辑后失焦自动保存（不用找保存按钮），下一轮分析即带上；确认没把内容写进别的节。
</details>

<details>
<summary><b>深浅色 / 主题不对？</b></summary>

页面颜色随系统深浅 + 主题色即时跟随；若异常，回主页再进即可触发重解析。
</details>
