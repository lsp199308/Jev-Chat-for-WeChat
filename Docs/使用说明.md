# Jev-Chat 使用与配置说明

> 一份看懂怎么填、怎么用的操作手册。功能介绍见仓库根目录 [README](../README.md)。

---

## 一、快速上手（三步开始）

1. **装好插件**（deb 装完重启微信），打开入口：**微信 → 我 → 设置 → Jev Chat**（或在系统设置/插件入口打开，取决于「插件入口位置」）。
2. **填 API**：进「意图判断」和「建议回复」两组，按下面第二、三节填好预设/地址、Key、模型。
3. **找人发条消息**：对方消息下方会自动出现分析卡片和 4 条建议回复，点 ➤ 直接发送。

---

## 二、意图判断（判断层）怎么填

设置路径：**Jev Chat → 意图判断**（配置项始终显示；「显示分析卡片」开关只控制卡片显隐，不影响下面的配置）。

| 设置项 | 怎么填 |
| --- | --- |
| **显示分析卡片** | 只控制卡片显隐：关了卡片不出分析块，但**判断仍在后台跑**（生成层的约束、自动回复的收线保护都要用）；判断层和生成层**都关**才完全不处理。**没配判断层 Key 时走本地规则兜底**（含收线判别），判断层零消耗 |
| **关联上下文** | 把最近 N 条消息一起给模型参考，建议 **5～10 条**；选「不关联」只看当前这条 |
| **服务预设** | 三选一：**博查 / 阿里百炼 / 自定义**，见下表 |
| **服务地址** | 选了博查/百炼会自动填好并**锁定**；只有「自定义」能手动输入 |
| **Key密钥** | 对应平台的 API Key（`sk-` 开头），**预设锁定状态下也照常可填可改** |
| **模型** | 同服务地址：预设自动填并锁定，自定义可手填 |

### 服务预设怎么选

| 预设 | 自动填入的地址 | 自动填入的模型 | 你还需要做 |
| --- | --- | --- | --- |
| **博查** | `https://jev.bocha.cn/v1/systemone` | `bocha-jev-v1` | 只填 Key |
| **阿里百炼** | `https://llm-tg7bn69qnisd67ok.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/systemone` | `decision-model-preview` | 只填 Key |
| **自定义** | 保留当前值，可手动修改 | 同左 | 地址、模型、Key 全部手填 |

- 预设选中后，点「服务地址 / 模型」会提示**预设已锁定**，防止误改；切回「自定义」即可解锁编辑（值保留，改哪个动哪个）。
- 两个预设都是 SystemOne 专用判断接口，插件自动走对应协议，其他都不用动。
- 自定义地址的规则：地址里含 `systemone` 走专用判断接口；否则按通用 `chat/completions` 接口处理（地址填到 `/v1` 为止即可）。

## 三、建议回复（生成层）怎么填

设置路径：**Jev Chat → 建议回复**（打开「建议消息」开关后才显示以下各项）。

### 1. 基础三项

| 设置项 | 怎么填 |
| --- | --- |
| **服务地址** | OpenAI 兼容地址，**填到 `/v1` 为止**，结尾的 `/chat/completions` 插件自动拼。常见示例见下表 |
| **Key密钥** | 对应平台的 API Key |
| **模型** | 平台的模型 ID，如 `qwen3.8-max`、`glm-4.6`、`deepseek-v3` 等 |

常见平台地址示例：

| 平台 | 服务地址 |
| --- | --- |
| 阿里百炼（专属接入点） | `https://llm-tg7bn69qnisd67ok.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |
| 阿里百炼（公共） | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` |
| SiliconFlow 硅基流动 | `https://api.siliconflow.cn/v1` |
| OpenAI | `https://api.openai.com/v1` |

### 2. 思考模式关闭（重点：填错会变慢、多花钱）

用带「深度思考」的模型（qwen3 系列、GLM-4.5+、GPT-5、Gemini 2.5 等）时，需要告诉接口**关闭思考**，否则回复慢、token 翻倍。**按你的生成层服务商选**：

| 你用的模型/平台 | 该选的选项 | 实际发送的参数 |
| --- | --- | --- |
| 不确定 / 混用 | **自动识别**（默认） | 按服务地址自动挑下面两种之一 |
| 模型本身不思考（如 deepseek-v3、glm-4-flash） | **不发送** | 不带任何参数 |
| 阿里百炼 Qwen3、SiliconFlow Qwen3 | **百炼 enable_thinking** | `"enable_thinking": false` |
| 智谱 GLM-4.5/4.6、豆包思考模型 | **GLM/豆包 thinking** | `"thinking": {"type": "disabled"}` |
| OpenAI GPT-5 / o 系列 | **OpenAI effort** | `"reasoning_effort": "minimal"` |
| OpenRouter 网关 | **OpenRouter** | `"reasoning": {"enabled": false}` |
| Gemini（经兼容网关） | **Gemini budget** | `"thinking_budget": 0` |
| vLLM 自部署 Qwen3 | **vLLM 自部署** | `"chat_template_kwargs": {"enable_thinking": false}` |

> 该设置只影响生成层（读心、起草、换一批、记忆更新）。判断层预设接口自动处理，无需关心。

### 3. 回复行为

| 设置项 | 说明 |
| --- | --- |
| **快捷回复** | 键盘上方常驻建议回复，不展开分析卡片也能直接选 |
| **话术模式（真实口吻）** | 开=按你自己的说话习惯落笔；关=纯按所选话术人设回 |
| **话术选择** | 15 种人设可多选：高情商话术、贴吧老哥、拒绝加班、卑微乙方、稳如老狗、已读乱回、鱼塘主、职场黑话、阴阳怪气、情绪价值、夸夸、讨好型人格、狗头军师系列 |

> **自动回复不在设置页**：它按联系人管理，在**记忆档案**里逐个开启（见第五节）。

## 四、其他功能开关

设置主页共六个入口：**基础功能 / 意图判断 / 建议回复 / 记忆档案 / 用量统计 / 插件版本**，点进去才是各自的具体设置。

| 设置项 | 位置 | 说明 |
| --- | --- | --- |
| **后台运行** | 基础功能 | 后台保活（场景修复 + 静音音频），无悬浮窗 |
| **消息防撤** | 基础功能 | 对方撤回时提示「已拦截 XX 撤回的消息」 |
| **微信运动** | 基础功能 | 步数按「总步数」目标全天平滑递增；「瞬间 88888」一键到位 |
| **记忆档案（开关）** | 记忆档案页 | 总开关，关=暂停读写（已存内容保留） |
| **查看记忆档案** | 记忆档案页 | 看每个人的相处笔记和自动回复设置 |
| **清除记忆档案** | 记忆档案页 | **全部**删除（单个删除在档案列表里操作） |
| **判断层/生成层用量** | 用量统计页 | 今日+累计 token 消耗，点开可清零 |
| **插件版本** | 主页 | 显示构建号，点按弹说明；与 deb 文件名对得上即装对 |

## 五、记忆档案日常操作

- **自动回复（按联系人）**：档案**列表页每一行右侧**，「自动回复」开关和「第N条 ▸」并排放在一起——**开关打开的联系人收到消息才自动回复**，点「第N条 ▸」选自动发第几条（1～4，开了自动回复后显示为主题色）。不开的人永远只出建议、不自动发。
- **自动成长**：每聊约 2 分钟，模型自动总结更新九大板块（这是TA / 我们之间 / 长期话题 / 近期动态 / 动态小结 / TA最近 / 待办承诺 / 画像小结 / 我的习惯）。
- **称呼与性别自动同步**：标题优先显示微信**备注**，没备注显示**昵称**；性别跟随微信资料，对方设为未知就不显示、也不传给模型。
- **手动编辑**：档案详情页右上「编辑」→ 改文字 →「完成」保存。没写到的板块保留原值，不会误清空。
- **删除一个人**：档案**列表**里**左滑**该联系人 → 删除（弹确认）。删除后该联系人再发消息会**重新建档**（称呼/性别重新自动识别，旧笔记不恢复；自动回复开关也随之重置为关）。返回后列表和「N 位联系人」计数自动刷新。
- **列表行只显示名字**：优先备注/昵称；没名字的联系人才显示 wxid 认人，关系、更新时间等都不显示。

## 六、常见问题

**Q：分析卡片标题显示的是什么名字？**
微信备注优先，其次昵称；都没有就显示「- 意图 -」。

**Q：收到消息到出卡片很慢？**
基本是思考模式没关对。去「建议回复 → 思考模式关闭」按上表选对选项；判断层慢就检查预设/Key 是否填对。

**Q：建议回复不满意？**
点 🔄 换一批（先出备用库存，用完自动重新生成）；或调整话术选择/关联上下文条数。

**Q：Key 会泄露吗？**
Key 只存在你手机本机，请求直连你填的服务地址，插件不经过任何第三方服务器。

**Q：单删和全清的区别？**
单删只删那一个人的档案（列表左滑）；「清除记忆档案」是所有人一起删。两者都不可恢复。

**Q：怎么确认装的是刚编译的新包？**
版本号带构建时间戳（如 `1.1.1-20261022.1259`）：设置页标题、主页「插件版本」行和记忆档案列表底部显示的就是当前运行的时间戳，和 deb 文件名里的对得上就是装对了；对不上就是包装错了/没重启微信。

**Q：开了自动回复为什么没有自动发？**
按顺序检查：①「建议消息」总开关是否开着；②这个联系人的开关是否在记忆档案列表里打开；③对方发的是不是收尾消息（晚安/睡了/去忙等）或纯应付消息（哈哈/嗯）——这两种故意不回，像真人；④分析期间你又手动回复过或来了新消息——旧结果作废，不回。
