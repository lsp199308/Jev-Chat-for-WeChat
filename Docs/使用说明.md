## 🚀 第一步：装上跑通

```text
① 安装并重启微信（首启会弹使用说明，输「我已阅读并理解」确认）
② 微信 → 我 → 设置 → Jev Chat
③ 意图判断页 + 建议回复页各配一层 API（推荐见下方「模型推荐」）
④ 启用插件 → 开总开关 → 勾联系人；群在「选择群聊」里勾
⑤ 回主页点「一键自检」，无报错即成功
⑥ 回到聊天界面，收到消息即可看到卡片
```

### ① 安装

| 项目 | 要求 |
| --- | --- |
| 系统 | iOS 14+（arm64 / arm64e） |
| 注入 | 越狱 Sileo 装 `.deb`，或巨魔注入 dylib |
| 作用域 | 仅微信（com.tencent.xin） |

装完**重启微信**生效。

### ② 找到插件入口

微信 → **我 → 设置 → Jev Chat**；或在微信「插件」页里的 Jev Chat（入口位置可在插件设置里切换）。

### ③ 配两层模型

插件分两层，各配一个大模型 API：

| 层 | 干什么 | 不配会怎样 |
| --- | --- | --- |
| 🧠 **判断层**（意图判断页） | 分析消息：意图、风险、策略、读心 | 走本地规则兜底，能出卡但没分析细节 |
| ✍️ **生成层**（建议回复页） | 写候选回复、代答、记忆笔记 | 没有候选和代答 |

两层可以填同一家；**只配生成层也能用**（判断走本地兜底，零 token）。推荐组合见「模型推荐」。

### ④ 选人

**启用插件 → 开总开关 → 勾联系人**。只有名单内的联系人才会被分析，名单外零请求零消耗。群在「选择群聊」里勾。

### ⑤ 体检

回主页点**「一键自检」**：两层连通性与延迟、名单、档案五层存储，10 秒确认装没装对。无报错即成功。

### ⑥ 用起来

回到聊天界面，对方来消息的一瞬间，聊天页里自动浮现一张**意图分析卡片**——对方在想什么、情绪如何、该不该立刻回、怎么回最合适，一目了然；并附上 **4 条像你自己说话的建议回复**，点 ➤ 直接发送。

### 💡 首启弹窗

每个新版本首启都会弹一次使用说明，输「我已阅读并理解」确认后本版本不再弹——升级 / 重装后会重新弹。

### 💡 找不到设置在哪

主页「🔍 找设置」：搜功能名（步数 / 皮肤 / 代答 / 备用…）直达对应设置页。

## 🏆 模型推荐（实测组合）

### 🧠 意图判断（判断层）——按推荐顺序

| 顺位 | 服务 | 配置方式 | Key 申请 | 说明 |
| :---: | --- | --- | --- | --- |
| ① 首选 | **阿里百炼** | 服务预设选「阿里百炼」，地址与模型自动锁定，只填 Key | [bailian.console.aliyun.com](https://bailian.console.aliyun.com/cn-beijing/model/settings/api-key) | SystemOne 专用网关实测 **0.2~0.4 秒**出判断，每题带概率与置信度，判断最准最跟手 |
| ② 兜底 | 任意 OpenAI 兼容大模型 | 服务预设选「自定义」，填地址 / Key / 模型三件套 | 各平台自行申请 | 百炼通用接口可填 `qwen3.8-max`（实测 2 秒左右）；⚠️ `decision-model-preview` 只在百炼 SystemOne 专用网关上存在，填到通用接口会报 403 |

### ✍️ 生成层——推荐 DeepSeek

[deepseek.com](https://www.deepseek.com) 申请 Key，便宜、快：

```text
服务预设：自定义
服务地址：https://api.deepseek.com
Key：     在 deepseek.com 申请
模型：     deepseek-flash        ← 首选：实测起草 1 秒左右，候选与判断联动好
          deepseek-chat         ← 稳妥备选：老款非思考模型，开箱即用
思考模式关闭：自动识别
```

其它 OpenAI 兼容模型也能用（百炼 Qwen 系列 / 智谱 GLM / Kimi 等）。**思考型模型**（Qwen3、GLM-4.5+、DeepSeek-R1 等）必须在「思考模式关闭」里按服务商选对写法（设置项里有逐家说明）——关不掉的思考会占满输出额度，卡片会报「思考占满额度、正文 0 条」。

### 📊 判断方式实测对比（2026-10，单条首聊场景）

同一套生产提示词，三种判断方式接同一生成层（deepseek-flash）对比：

| | ① 百炼 SystemOne 预设 | ② 百炼通用接口 qwen3.8-max | ③ 全 DeepSeek deepseek-flash |
| --- | :---: | :---: | :---: |
| 判断耗时 | **0.2~0.4 秒** | 2.0~2.1 秒 | 1.1~1.2 秒 |
| 判断输入 | 约 1318 token（问卷在服务端展开） | 约 470 token | 约 450 token |
| 请求数 | 2 次（读心并入起草，省流开） | 2 次（读心并入判断） | 2 次（读心并入判断） |
| 结构化输出 | **每题概率+置信度**，另有附加题 | JSON 五项 | JSON 五项 |
| 读心 | 独立串行、被判断结论锚定，**给打法也给雷点** | 并在判断里，观察陈述型 | 并在判断里，打法型 |
| 候选与判断联动 | **最强** | 中 | 中 |

**结论与建议**：

- **要最准：判断层选「阿里百炼」预设 + 生成层 deepseek-flash**。SystemOne 的优势在结构（逐题问答、私聊动作词表、读心锚定起草），不在模型本身；代价是判断 token 约 3 倍；读心随起草一起回（省流开），总链路 2 秒上下。
- **要省事：判断层「自定义」也填 deepseek-flash**（地址 api.deepseek.com），全链一层一个 Key，质量差距主要在读心的打法感和候选联动上。
- 极速模式与 SystemOne 互斥（极速走生成层通用接口）；群自定义规则遇 SystemOne 网关会自动回落生成层通用接口，属正常。

## 🧠 意图判断页——每行怎么填

入口：主页 → 意图判断。

| 设置项 | 作用 | 怎么填 |
| --- | --- | --- |
| **显示分析卡片** | 总闸：开了聊天页才出卡。关了卡片不显示，但判断仍在后台跑（生成层约束 / 自动回复收线保护要用） | 日常开 |
| **分段等待** | 等这么久没新消息才分析——短=出卡快，长=对方连发的分段消息能合并成一条分析，更稳 | 快（1.5 秒）/ 标准（3 秒）。对方爱连发选快，想稳选标准 |
| **卡片显示字段** | 卡片上每类内容（意图 / 策略 / 读心 / 风险等）独立显隐 | 按喜好勾 |
| **关联上下文** | 判断时带最近几条聊天记录，分得清当下与旧账 | 默认 12 条 |
| **服务预设 / 地址 / Key / 模型** | 判断层大模型配置 | 见「模型推荐」 |
| **思考模式关闭** | 思考型模型要按服务商选对关思考的写法，否则思考占满输出额度 | 自动识别覆盖绝大多数 |

### 省流四开关

| 开关 | 效果 |
| --- | --- |
| **应付消息不分析** | 哈哈 / 嗯 / 纯表情本地跳过，零请求 |
| **同内容复用分析** | 同内容 5 分钟内沿用上次结果；判断配置一变旧结果自动作废 |
| **读心并入判断** | 读心不单独发请求（通用并入判断、SystemOne 并入起草） |
| **极速模式** | 判断+候选一次请求，最省（走生成层配置） |

### 判断增强

- **高危双判**：风险 ≥5 的消息自动用生成层模型复核一次、取两者较高值，卡片显示
- **判断对比测试**：同一条消息双路判断并排展示，用来调模型
- **备用线路（自动接管）**：主判断线路请求失败（超时 / 服务端报错 / 422 预算）时，自动改用备用配置按通用接口重判一次——服务端炸了判断不至于整段趴窝。开关 + 备用地址 + Key + 备用模型三项配齐才生效；备用固定走 OpenAI 兼容接口（百炼通用接口可填 `qwen3.8-max`），关思考沿用主线路设置。接管过程写进日志（`[判断] 主线路失败…切换备用线路`）

### 判断 buff（无需设置，自动生效）

- **第二意图候选**：第二可能 ≥15% 时，末 2 条候选按它换角度写
- **上下文带时间**：历史行带时间戳，分得清「刚刚」与「上周」
- **采纳反馈进判断**：你亲自选用的候选回流判断层当分寸参考（群聊 / 私聊分开取材，群里的客服腔不会带进私聊）
- **跨设备补洞**：隔 30 分钟回归，自动拉库补上电脑端聊的中段
- **记忆按价值分流**：随口闲聊的低价值轮次自动跳过笔记重写，不多花 token
- **前情摘要**：长对话掉出上下文窗口的部分自动压缩成 ≤400 字摘要注入，被提起的旧事按摘要接话

### 📝 自定义人设卡

建议回复 → 话术选择 → 新增人设：

1. **粘贴导入**：把社区人设卡（SKILL.md）全文复制到剪贴板，点「粘贴剪贴板（自动清洗）」——自动剥掉 frontmatter / 元信息，只留正文
2. **选文件导入**：点「选文件导入（自动清洗）」，在文件 App 里选 .md / .txt，支持 UTF-8 / GB18030 / UTF-16 编码，同样走自动清洗
3. 也可以直接手写：**身份与性格 → 说话风格（句式、语气、口头禅）→ 分寸（什么不做）**
4. 保存后在「话术选择」里勾选，即可让建议回复按这个人设说话

### 🤖 自动回复

开关在**记忆档案列表每行右侧** + 「第N条 ▸」设置收到第几条自动回。防线全自动，不用管：

- 收线 / 应付消息不回；10 秒最多回 2 条
- 冲突期自动刹车，防火上浇油
- AI 代发的内容不进画像、不进语料（AI 不学 AI）
- 分身值守的会话按分身口径走

## 🗂 记忆档案

入口：主页 → 记忆档案。按联系人维护，越用越懂 TA。

### 相处笔记（12 节，自动成长)

这是TA / 我们之间 / 长期话题 / 近期动态 / 动态小结 / TA最近 / 待办承诺 / 画像小结 / 我的习惯 / TA的表达习惯 / TA的吵架模式 / TA的和好方式——聊天自动更新，点「编辑」可直接改，改完自动落盘。

### 【备注】写死的事实（模型只读）

联系人笔记底部的【备注】写**必须遵守**的事实，一行一条，判断 / 读心 / 起草都遵守：

```text
【备注】
对花生芒果过敏，永远别提相关甜品
我是做后端的，别建议我转行
每周三晚固定加班，别约这个时间
```

### 联系人规则

联系人笔记右上「规则」：**判断规则 + 起草规则**两张卡，怎么判、怎么说话你说了算，非空即生效。内置 4 套模板（家人 / 领导 / 朋友 / 伴侣）套用后直接改。规则直接进 SystemOne 快车道。

### 关系统计

记忆档案右上「统计」：聊天频率 / 话题 Top5 / 档案健康度 / 待办未清，纯本地现算。

## 🤖 我的分身

入口：主页 → 我的分身。睡觉了它替你值守：免白名单监控所有私聊、按你的作息窗口代答、边界刹车兜底、醒来待主理队列集中交账。

### 三个开关各管一层

| 开关 | 管什么 |
| --- | --- |
| **① 分身总开关** | 白名单外的人：出卡、判断、建档；关 = 非白名单走正常通道 |
| **② 代答总开关** | 自动回复总闸——开 = 按分身画像代答；关 = 只出卡不代答 |
| **③ 陌生人代答** | 单独控制白名单外是否被自动回复 |

### 代答口径

- **白名单**（开着各自自动回复开关的）：「主人在忙 / 不在」开头、按分身画像
- **白名单外**：按分身画像（需③陌生人代答开）
- **睡眠窗口内**：深夜值守腔（轻声接住、急事留言）；**窗口外**：正常腔

### 作息引擎

出站消息按小时分布自动学你的睡眠窗口，学到的窗口可手动改（改过就停自动学习）。

### 过滤名单

不想让分身接的人加进过滤名单：过滤的人**不自动回复**；如果同时在白名单里，按白名单处理（白名单优先）。

### 分身专属开关

| 开关 | 管什么 |
| --- | --- |
| **分身发言给大模型看** | 分身代答过的内容要不要进后续对话上下文——默认关（陌生人乱问的烂内容不会带偏你亲聊时的 AI） |
| **会话状态机（分身代答用）** | 分身代答的会话走不走前情注入与态势判断——默认开（冲突期照常刹车）；关 = 分身无视态势照样回 |

### 边界刹车（硬规则，不可关）

钱 / 承诺 / 邀约 / 健康 / 风险≥5——一句话不代答，转待主理。会话状态机冲突刹车也保留。

### 分身画像（独立于原始数字画像）

六层蒸馏结构（硬规则 / 身份节奏 / 表达 / 决策 / 人际 / 纠错）+【备注·我的职业】。代答总开关开时**高于一切**（含判断层约束）。页内可编辑、套用模板；「允许大模型修改」开着时夜间按近期对话微调（硬规则底线不动）。

### 待主理队列

分身拿不准的（画像无依据 / 触发边界刹车）不硬答，进**待主理队列**，你醒来看一眼集中处理。主页「我的分身」行实时显示队列条数。

### 其他

- **代答只出一条**：每次只生成一条并自动发出，第二行附署名（缺省「——AI回复」，可编辑 / 清空）
- **分身对话不进记忆档案**：分身说的话不是你说的话
- **悬浮球**：可拖动圆球，绿=代答开 / 灰=关，点按切换；静置 5 秒收成贴边粗竖线

## 👥 群聊

### 勾群

启用插件 → 选择群聊 → 勾白名单群。只有勾了的群才会处理。

### 群类型五选一

闲聊通用 / 商业客服 / 家族群 / 公司群 / 游戏群——意图集与接话口径按类型切换。新群首次触发按群名自动猜，猜错可在群笔记里改。

### 触发三档

| 档位 | 行为 |
| --- | --- |
| **@我才回** | 默认推荐 |
| **值得回才回** | 每条先小问卷筛一遍，值得答的才分析——活跃群省钱不吵群 |
| **所有消息都回** | 极低频群 |

### 群笔记与业务知识

群笔记按类型建档。底部的**【业务知识】**写死价格 / 发货 / 售后，一行一条，群里问价报价以此为准：

```text
【业务知识】
店铺：XX服装店
价格带：卫衣 89-129，T恤 39-59
发货：48小时内发
售后：7天无理由
```

### 群自定义规则

群笔记里设**判断规则 + 起草规则**，5 套内置模板（淘宝客服 / 工作群 / 家长群 / 兴趣群）。

### 群员画像

白名单群逐人自动建档（最近发言 + 我的回应），判断和起草都带这份档案。群笔记详情 → 群员档案查看 / 删除。每群封顶 20 人、14 天不发言停用。

### ❓ 常见问题

<details>
<summary><b>插件入口在哪？</b></summary>

微信 → 我 → 设置 → Jev Chat；或微信「插件」页里的 Jev Chat（入口位置可在设置里切换）。
</details>

<details>
<summary><b>收消息没有卡片？</b></summary>

按序检查：① 启用插件总开关 + 该联系人/群在名单里；② 判断层或生成层至少配好一层；③ 群消息需要 @我（或触发档位不是「@我才回」）；④「值得回」档有 60 秒冷却，连续消息只有第一条参与判定。
</details>

<details>
<summary><b>改了业务知识 / 备注没生效？</b></summary>

编辑后失焦自动保存（不用找保存按钮），下一轮分析即带上；确认没把内容写进别的节。
</details>

<details>
<summary><b>开了极速模式，群规则好像没生效？</b></summary>

极速与自定义互斥是设计行为：写了规则的群自动回完整链路，规则照常生效；其它群照常极速。
</details>

<details>
<summary><b>群员档案里只有新发言、老成员不全？</b></summary>

装包后冷启动回灌会把历史发言按水位线补进档案（防重复计数）；更早于回灌范围的（微信只留最近几十条）天然没有。
</details>

<details>
<summary><b>深浅色 / 主题不对？</b></summary>

页面颜色随系统深浅 + 主题色即时跟随；若异常，回主页再进即可触发重解析。
</details>

<details>
<summary><b>重装插件后设置会丢吗？</b></summary>

不会。配置与记忆档案都存在微信沙盒与 Keychain 里，重装 / 升级插件不动它们，登录后自动按账号回灌。
</details>
